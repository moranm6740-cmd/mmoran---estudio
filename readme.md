# Mario Morán - Sitio Web de Fotografía Profesional

## Propósito del Proyecto
Página web institucional y portafolio interactivo para el estudio de fotografía **Mario Morán**. Diseñado con una estética oscura, elegante y minimalista que destaca el trabajo fotográfico organizado por categorías y facilita el contacto directo.

## Características Técnicas
- **Estructura Semántica HTML5:** Uso de etiquetas `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.
- **Hojas de Estilo Externa (CSS):** Implementación de variables, paleta de colores oscura, transiciones y diseño responsivo.
- **Flexbox:** Aplicado en la sección de servicios fotográficos.
- **CSS Grid:** Utilizado en el portfolio de 30 imágenes totales (5 por cada uno de los 6 estilos) y en la sección de reseñas.
- **Interactividad (JavaScript):** Manipulación del DOM para efectos de desplazamiento (*scroll*) en el encabezado.
- **Formulario de Contacto:** Integración funcional con el servicio Formspree.
- **Despliegue:** Optimizado para GitHub Pages y Netlify.
